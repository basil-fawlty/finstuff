Cumulative advantage by horizon

Inside wrapper: all turnover gains deferred to withdrawal/liquidation, taxed at τC on full nominal gain since original deposit P. Outside: turnover realises gains immediately, basis steps up. Values in real ₪ when inflation-adjusted mode is on.

Model equations

Each year t = 1 … n

Growth

B_outside(t) = B(t−1) × (1 + R)
B_wrapper(t) = B(t−1) × (1 + R − f)

Turnover tax — outside only (inside wrapper: no event)

tax_turn = (B − basis) × turn × τ_out  [nominal gain]
basis_new = basis × (1−turn) + (B×turn − tax_turn)  [step-up]
B = B − tax_turn

Withdrawal amount

w_t = w × (1 + i)^(t−1) / (1 + R)  [inflation-adjusted]

Withdrawal tax

gain_outside = max(0, B − basis) × w_t  [nominal gain]
gain_wrapper = max(0, B − P) × w_t  [since original deposit P]
tax_wd = gain × τ  ·  net_wd = gross − tax_wd  ·  basis × (1 − w_t)

Terminal liquidation (year n)

term_gain_outside = max(0, B − basis)  [nominal]
term_gain_wrapper = max(0, B − P)  [all deferred turnover gains taxed now at τ_C]
terminal_tax = term_gain × τ

Total value (real ₪ when inflation-adjusted on)

total = Σ net_wd_t / (1+i)^t + (B_n − terminal_tax) / (1+i)^n

Advantage decomposition

rate_benefit = total_wrapper(turn=0) − total_outside(turn=0)
turn_benefit = total_outside(turn=0) − total_outside(turn=T)
fee_drag = tax_saved_gross − net_advantage
net_advantage = rate_benefit + turn_benefit − fee_drag
